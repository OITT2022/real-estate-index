API Documentation
Version: 1.0
Base URL: https://www.Advplanner.com/api/v1

1. Authentication
All requests require a Bearer token in the Authorization header. This token is provided by the AradRE administrator upon API client creation.
Header Format:
HTTP
Authorization: Bearer YOUR_API_TOKEN
Error Response (401 Unauthorized):
If the token is missing or invalid:
JSON
{ "error": "Unauthorized" }

2. Endpoints
2.1 Get Properties
GET /api/v1/properties
Returns all published properties enabled for API access.
Query Parameters
Parameter
Type
Description
city
string
Filter by city name (partial match, case-insensitive)
propertyType
string
Filter by type (e.g., Apartment, Penthouse, Duplex)
page
number
Page number (default: 1)
limit
number
Results per page (default: 50, max: 100)
Example Request
Bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://www.aradre.com/api/v1/properties?city=Larnaca&limit=10"

2.2 Get Projects
GET /api/v1/projects
Returns all published projects enabled for API access, including linked properties, images, and documents.
Example Request
Bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://www.aradre.com/api/v1/projects

4. Implementation Details
Field Availability & Permissions
The fields returned depend on your API client configuration set by the administrator.
* Images: Included only if "Include Images" is enabled. The primary image is always first in the array.
* Documents: Included only if "Include Documents" is enabled. Categories include plan, brochure, or other.
Visibility Rules
Only entities meeting these criteria are returned:
1. Published by admin.
2. Status is ACTIVE.
3. API Enabled flag is ON.

5. Code Examples
JavaScript (Fetch)
JavaScript
const response = await fetch('https://www.aradre.com/api/v1/properties', {
    headers: { 'Authorization': `Bearer ${TOKEN}` }
});
const result = await response.json();
console.log(result.data);
Python (Requests)
Python
import requests
headers = {'Authorization': f'Bearer {TOKEN}'}
response = requests.get('https://www.aradre.com/api/v1/properties', headers=headers)
data = response.json()['data']
PHP (cURL)
PHP
$ch = curl_init('https://www.aradre.com/api/v1/properties');
curl_setopt($ch, CURLOPT_HTTPHEADER, ["Authorization: Bearer $token"]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
