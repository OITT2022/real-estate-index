# Phase Plan

## Phase 1 — Scaffold
Done when:
- app structure exists
- env template exists
- README and CLAUDE docs exist
- basic homepage route and admin route exist

## Phase 2 — Database
Done when:
- Prisma schema exists
- migration runs
- demo seed works
- property, image, inquiry, admin models are connected

## Phase 3 — Public homepage
Done when:
- property grid renders from DB
- filters work
- cards link to property pages
- mobile layout works

## Phase 4 — Property details page
Done when:
- page resolves by slug
- gallery displays
- specs render
- map renders from coordinates
- video section works
- inquiry form saves to DB

## Phase 5 — Admin auth and dashboard
Done when:
- login works
- protected admin layout exists
- property list screen works

## Phase 6 — Property CRUD
Done when:
- create/edit/delete flows exist
- validation works
- publish toggle works
- status field works

## Phase 7 — Media handling
Done when:
- multiple images supported
- primary image supported
- image ordering supported
- video URL supported

## Phase 8 — Inquiry management
Done when:
- inquiry form persists to DB
- admin can review inquiries
- optional email notifications can be added

## Phase 9 — Production polish
Done when:
- sitemap and robots exist
- metadata is dynamic
- loading/error/empty states exist
- app is deployment-ready
