## 1. מבוא

מערכת AradRe היא פלטפורמה לניהול אינדקס נדל"ן הכוללת:
- **אתר ציבורי** להצגת נכסים ופרויקטים למכירה
- **פאנל ניהול** לניהול נכסים, פרויקטים, פניות, לקוחות ומשתמשים
- **מערכת CRM** לניהול ליד, הערות, פגישות ושליחת מיילים
- **API חיצוני** לשילוב עם מערכות צד שלישי
- **תמיכה ברב-דיירות (Multi-tenancy)** — ניתן להקצות נכסים ופרויקטים ללקוחות שונים

המערכת בנויה על Next.js עם TypeScript, מסד נתונים PostgreSQL, ואחסון קבצים מקומי או ב-S3.

## 2. כניסה למערכת

### כתובת כניסה
```
https://[domain]/admin/login
```

### תהליך הכניסה
1. הזינו כתובת **דוא"ל** וכן **סיסמה**
2. לחצו **Sign in**
3. במקרה של הצלחה — תועברו ללוח הבקרה
4. במקרה של כישלון — תוצג הודעת שגיאה "Invalid email or password"

### הערות חשובות
- **אין מנגנון שחזור סיסמה.** במקרה של שכחת סיסמה, יש לפנות למנהל המערכת (Super Admin) לאיפוס.
- **אין אימות דו-שלבי (2FA/OTP).** הכניסה מבוססת על דוא"ל וסיסמה בלבד.
- ניתן להשבית משתמש (שדה "Active") כדי למנוע ממנו להתחבר.

## 4. תפקידים והרשאות

### סוגי משתמשים

#### Super Admin (מנהל מערכת)
- גישה מלאה לכל הדפים וכל הנתונים
- יכול לנהל את כל הלקוחות, המשתמשים, הנכסים והפרויקטים
- יכול ליצור ולנהל משתמשי מערכת נוספים

#### Customer Manager (מנהל לקוח)
- גישה מוגבלת לדפים שהוקצו לו בלבד
- רואה רק נתונים של הלקוח (חברה) שהוא שייך אליו
- לא יכול לראות או לערוך נתונים של לקוחות אחרים
- ביצירת נכס/פרויקט — הלקוח מוקצה אוטומטית
- יכול ליצור משתמשים חדשים רק בתוך הלקוח שלו

#### משתמש רגיל (Regular Admin)
- גישה לדפים שהוקצו לו בלבד
- ללא שיוך ללקוח ספציפי

### הרשאות דפים
כל משתמש שאינו Super Admin מקבל רשימת דפים מותרים:
`dashboard`, `homepage`, `properties`, `projects`, `inquiries`, `calendar`, `customers`, `maps`, `api`, `users`

אם דף לא מותר — הוא לא מופיע בתפריט ולא ניתן לגשת אליו.

## 6. ניהול נכסים (Properties)

**נתיב:** `/admin/properties`

### רשימת נכסים
- טבלה עם כל הנכסים (מסוננים לפי הרשאות משתמש)
- עמודות: כותרת, עיר, מחיר, סוג, סטטוס פרסום
- סינון לפי לקוח (Customer) — זמין ל-Super Admin בלבד
- כפתור **+ New Property** ליצירת נכס חדש

### יצירת נכס חדש
**נתיב:** `/admin/properties/new`

תהליך יצירה מרובה שלבים (CreatePropertyFlow):

#### שלב 1 — טופס נכס
**שדות חובה:**
| שדה | תיאור | דוגמה |
|------|-------|-------|
| Title | כותרת הנכס | Sea View Penthouse |
| Slug | כתובת URL ייחודית (נוצר אוטומטית מהכותרת) | sea-view-penthouse |
| City | עיר | Larnaca |
| Address | כתובת מלאה | Skala Area, Larnaca |
| Description | תיאור מפורט (מינימום 10 תווים) | — |
| Price | מחיר (מספר חיובי) | 820000 |
| Seller Name | שם איש קשר | Sales Office |
| Seller Email | דוא"ל איש קשר | sales@example.com |
| Seller Phone | טלפון (מינימום 5 תווים) | +357-99-123456 |
| Latitude / Longitude | קואורדינטות (ניתן לבחור מהמפה) | — |

**שדות אופציונליים:**
| שדה | תיאור |
|------|-------|
| Short Description | תיאור קצר לכרטיסים |
| Neighborhood | שכונה |
| Property Type | סוג (דירה, בית, פנטהאוז וכו') |
| Bedrooms | מספר חדרי שינה |
| Bathrooms | מספר חדרי אמבט |
| Area sqm | שטח במ"ר |
| Floor | קומה |
| Unit Number | מספר יחידה |
| Video URL | קישור לסרטון |
| Website URL | קישור לאתר |
| Currency | מטבע (ברירת מחדל: EUR) |
| Project | שיוך לפרויקט |
| Customer | שיוך ללקוח |
| Meta Title / Meta Description | שדות SEO |

**אפשרויות סימון:**
- Parking, Balcony, Swimming Pool, Elevator, Fireplace
- Cooling Type, Heating Type

**פרסום:**
- Published — מפורסם באתר הציבורי
- Featured — מסומן כמומלץ (מוצג בדף הבית)
- Sold — סומן כנמכר

**מפה / גיאולוקציה:**
- בהקלדת עיר וכתובת — מופיעה שורה כחולה לחיצה עם הכתובת המלאה
- לחיצה על הכתובת — המערכת מחפשת את הקואורדינטות אוטומטית (Geocoding)
- ניתן גם ללחוץ על המפה ישירות לבחירת מיקום
- ניתן להקליד קואורדינטות ידנית

#### שלב 2 — העלאת תמונות
- גרירה או בחירת קבצים (JPEG, PNG, WebP, GIF, עד 20MB)
- ניתן לבחור תמונה ראשית (Primary)
- ניתן לשנות סדר תמונות (גרירה)
- ניתן לבחור מספריית התמונות (Image Bank)

### עריכת נכס
**נתיב:** `/admin/properties/[id]`

אותם שדות כמו יצירה, בתוספת:
- ניהול תמונות (העלאה, מחיקה, סידור מחדש, הגדרת ראשית)
- שינוי סטטוס פרסום
- מחיקת נכס

### סטטוסים
| סטטוס | משמעות |
|--------|--------|
| DRAFT | טיוטה — לא מוצג באתר |
| ACTIVE | פעיל — מוצג באתר (אם published = true) |
| SOLD | נמכר |
| ARCHIVED | בארכיון |

**לוגיקת סטטוס אוטומטית:**
- אם `sold = true` → סטטוס SOLD
- אם `published = true` → סטטוס ACTIVE
- אחרת → סטטוס DRAFT

## 7. ניהול פרויקטים (Projects)

**נתיב:** `/admin/projects`

### רשימת פרויקטים
- טבלה עם כל הפרויקטים
- עמודות: כותרת, יזם, עיר, יחידות, סטטוס
- סינון לפי לקוח

### יצירת פרויקט — אשף 5 שלבים
**נתיב:** `/admin/projects/new`

#### שלב 1 — פרטי פרויקט
**שדות חובה:**
| שדה | תיאור |
|------|-------|
| Title | שם הפרויקט |
| Slug | כתובת URL |
| Developer Name | שם היזם |
| City | עיר |
| Address | כתובת |
| Description | תיאור מפורט |
| Latitude / Longitude | מיקום (מפה + geocoding) |

**שדות אופציונליים:**
| שדה | תיאור |
|------|-------|
| Short Description | תיאור קצר |
| Completion Date | מועד סיום משוער |
| Total Units | מספר יחידות כולל |
| Video URL | קישור לסרטון |
| Website URL | קישור לאתר |
| Customer | שיוך ללקוח |
| Meta Title / Meta Description | SEO |

#### שלב 2 — תמונות
- העלאת תמונות פרויקט
- ניהול סדר, ראשית, מחיקה
- בחירה מספריית תמונות

#### שלב 3 — מסמכים
- העלאת מסמכים (PDF, תמונות)
- תוכניות, ברושורים, מצגות

#### שלב 4 — מבנה הפרויקט (Project Structure)
- הגדרת בניינים, כניסות, קומות ויחידות
- **יצירה אוטומטית** — הגדרת מספר בניינים, כניסות, קומות ויחידות בקומה
- **הוספה ידנית** — הוספת קומה או יחידה בודדת
- **שיוך נכסים** — קישור נכס (Property) ליחידה ספציפית
- **מחיקה** — מחיקת קומה או יחידה (לא ניתן למחוק יחידה עם נכס משויך)

#### שלב 5 — תצוגה תלת-ממדית (3D Preview)
- תצוגה תלת-ממדית של מבנה הפרויקט
- אפשרות להעלאת קובץ סביבה (HDR/EXR) לתאורת הסצנה
- קבצים גדולים (עד 100MB) נתמכים דרך העלאה ישירה ל-S3

### סטטוסים
| סטטוס | משמעות |
|--------|--------|
| DRAFT | טיוטה |
| ACTIVE | פעיל — מוצג באתר |
| COMPLETED | הושלם |
| ARCHIVED | בארכיון |

## 8. ניהול פניות / CRM (Inquiries)

**נתיב:** `/admin/inquiries`

### מקורות פניות
1. **טופס באתר הציבורי** — מבקר באתר ממלא פניה בדף נכס או פרויקט
2. **יצירה ידנית** — מנהל יוצר פניה מהפאנל

### רשימת פניות
- טבלה עם: שם, נכס, סטטוס, תאריך
- סינון לפי סטטוס

### יצירת פניה ידנית
**נתיב:** `/admin/inquiries/new`

| שדה | חובה | תיאור |
|------|------|-------|
| Full Name | כן | שם הפונה |
| Email | כן | דוא"ל |
| Phone | לא | טלפון |
| Message | כן | תוכן הפניה |
| Property | כן | הנכס שאליו הפניה |
| Project | לא | פרויקט (אופציונלי) |

### ניהול פניה (CRM)
**נתיב:** `/admin/inquiries/[id]`

מסך CRM מלא עם 4 אזורים:

#### פרטי פניה
- שם, דוא"ל, טלפון, הודעה
- נכס ופרויקט משויכים
- תאריך יצירה

#### עדכון סטטוס
סטטוסים זמינים:
| סטטוס | משמעות |
|--------|--------|
| new | פניה חדשה |
| contacted | נוצר קשר |
| meeting_scheduled | נקבעה פגישה |
| negotiating | במו"מ |
| closed_won | נסגרה בהצלחה |
| closed_lost | נסגרה ללא הצלחה |

#### הוספת הערות
- הערות חופשיות לכל פניה
- כל הערה מתועדת עם תאריך ושם היוצר

#### קביעת פגישות
- הוספת פגישה עם תאריך ושעה ותיאור
- סטטוסים: scheduled, completed, cancelled

#### שליחת מייל
- שליחת מייל ישירות מהמערכת לפונה
- הזנת נושא ותוכן
- המייל נשלח דרך שירות Resend ומתועד ב-EmailLog

## 10. ניהול לקוחות (Customers)

**נתיב:** `/admin/customers`

### תיאור
ניהול חברות / לקוחות המשתמשים במערכת. כל לקוח יכול להיות בעלים של נכסים, פרויקטים, ומשתמשים.

### רשימת לקוחות
- טבלה עם שם חברה, איש קשר, פרטי התקשרות

### יצירת / עריכת לקוח
**שדות:**
| שדה | חובה | תיאור |
|------|------|-------|
| Company Name | כן | שם החברה |
| Logo | לא | לוגו (העלאה) |
| Description | לא | תיאור |
| Contact Name | לא | שם איש קשר |
| Contact Email | לא | דוא"ל |
| Contact Phone | לא | טלפון |

### דף עריכת לקוח
בנוסף לטופס, מוצגים:
- רשימת פרויקטים של הלקוח
- רשימת נכסים של הלקוח
- קישורים מהירים ליצירת נכס/פרויקט חדש ללקוח

### מחיקת לקוח
ניתן למחוק לקוח. **שימו לב:** יש לוודא שאין נכסים או פרויקטים או משתמשים מקושרים לפני מחיקה.

## 11. ניהול משתמשים (Users)

**נתיב:** `/admin/users`

### רשימת משתמשים
- טבלה עם שם, דוא"ל, תפקיד, סטטוס פעיל
- Customer Manager רואה רק את המשתמשים של הלקוח שלו

### יצירת / עריכת משתמש
**שדות:**
| שדה | חובה | תיאור |
|------|------|-------|
| Name | כן | שם מלא |
| Email | כן | דוא"ל (ייחודי) |
| Password | כן (יצירה) / לא (עריכה) | סיסמה (מוצפנת bcrypt) |
| Phone | לא | טלפון |
| Profile Image | לא | תמונת פרופיל |
| Super Admin | לא | האם מנהל מערכת |
| Customer | לא | שיוך ללקוח |
| Allowed Pages | כן | רשימת דפים מותרים |
| Active | כן | האם המשתמש פעיל |

### הרשאות דפים
בעת יצירת/עריכת משתמש, ניתן לסמן אילו דפים יהיו נגישים:
- Dashboard, Home Page, Properties, Projects
- Inquiries, Calendar Schedule, Customers

## 14. ניהול API (API Clients)

**נתיב:** `/admin/api`

### תיאור
ניהול טוקנים לגישה ל-API החיצוני של המערכת. מאפשר למערכות צד שלישי לקרוא נתוני נכסים ופרויקטים.

### רשימת לקוחות API
- טבלה עם שם, תחילית טוקן, היקף, סטטוס

### יצירת לקוח API
**שדות:**
| שדה | חובה | תיאור |
|------|------|-------|
| Name | כן | שם הלקוח |
| Description | לא | תיאור |
| Scope Type | כן | "all" (כל הנתונים) או "customer" (לקוח ספציפי) |
| Customer | תלוי | חובה אם scope = customer |
| Allowed Property Fields | כן | אילו שדות נכס חשופים |
| Allowed Project Fields | כן | אילו שדות פרויקט חשופים |
| Include Images | כן | האם לכלול תמונות |
| Include Documents | כן | האם לכלול מסמכים |
| Active | כן | האם הטוקן פעיל |

### לאחר יצירה
- מוצג טוקן חד-פעמי — **יש לשמור אותו מיד!** הטוקן לא יוצג שוב.
- ניתן ליצור טוקן חדש (Regenerate) אך הישן יבוטל.

### שימוש ב-API
```
GET /api/v1/properties
GET /api/v1/projects
Authorization: Bearer <token>
```

**פרמטרים (Properties):**
- `city` — סינון לפי עיר
- `propertyType` — סינון לפי סוג
- `page` — מספר עמוד (ברירת מחדל: 1)
- `limit` — תוצאות בעמוד (ברירת מחדל: 50, מקסימום: 100)

### הפעלת API לנכס/פרויקט
כדי שנכס או פרויקט יהיה זמין דרך ה-API, יש להפעיל את דגל **API Enabled** בדף עריכת הנכס/פרויקט (מופיע כ-toggle).

## 17. שאלות נפוצות

### כיצד מפרסמים נכס באתר?
בעריכת הנכס, סמנו את תיבת **Published** ולחצו שמור. הנכס יקבל סטטוס ACTIVE ויופיע באתר.

### כיצד מסמנים נכס כנמכר?
בעריכת הנכס, סמנו את תיבת **Sold** ולחצו שמור. הנכס יקבל סטטוס SOLD.

### כיצד מוסיפים נכס לפרויקט?
ביצירת/עריכת נכס, בחרו פרויקט בשדה **Project**. לחלופין, בדף עריכת הפרויקט (שלב 4), שייכו נכס ליחידה ספציפית.

### כיצד עובד ה-Geocoding?
1. הקלידו **עיר** ו**כתובת** בשדות הרלוונטיים
2. גלו למטה לאזור ה-Location
3. תופיע שורה כחולה עם הכתובת המלאה
4. לחצו על השורה — המפה תעוף למיקום שנמצא והקואורדינטות יתעדכנו

### שכחתי סיסמה, מה עושים?
אין מנגנון שחזור עצמאי. פנו למנהל המערכת (Super Admin) שיאפס את הסיסמה עבורכם.

### איך יוצרים טוקן API?
גשו ל-**System > API Clients > + New Client**, הגדירו את ההרשאות, ולאחר היצירה **העתיקו את הטוקן מיד** — הוא מוצג פעם אחת בלבד.

### מדוע אני לא רואה את כל הדפים בתפריט?
הגישה שלכם מוגבלת על ידי מנהל המערכת. פנו ל-Super Admin לקבלת הרשאות נוספות.

### מדוע פניות מטופס "צור קשר" לא מופיעות ברשימת הפניות?
טופס "צור קשר" הציבורי שולח מייל בלבד ואינו שומר את הפניה במסד הנתונים. פניות ממוקדות נכס/פרויקט כן נשמרות.
